# В ГНУ/Линукс ПО и пакеты скачиваються не как на виндовс, они скачиваються через пакетные менеджеры

**Пример скачки (на арч base линукс)**
```bash
sudo pacman -S yourprogramm # Вместо yourprogramm твоя программа
```

## С другими пакетниками чуть разные комманды, список пакетников можете найти в файле:
