
# Из файла можно полностью удалить всё содержимое и записать туда то, что ты хочешь, например:

```bash
echo "Новая единственная строка" > файл.txt
````

- `echo` - команда для вывода текста в консоль (подробнее чуть позже в файле [[echo|echo.md]])
    
- `"Новая единственная строка"` - ваша строка
    
- `>` - этот знак перенаправляет вывод в файл и **ПОЛНОСТЬЮ** перезаписывает его старое содержимое
    
- `файл.txt` - это ваш файл
    

Можно ещё добавить строку в конец файла, не удаляя старое:

```bash
echo "Ещё одна строка" >> файл.txt
```

Всё то же самое, но `>>` дописывает строку в конец файла.
