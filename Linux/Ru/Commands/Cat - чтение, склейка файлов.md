**Её главная задача -- читать данные из одного или нескольких файлов (или с клавиатуры) и выводить их сплошным потоком в терминал.**

# Нормальное применение (базовые сценарии)

## Быстро прочитать небольшой файл:
```bash
cat file.txt
```
**Вывод: то что было  в файле**

## Склеить несколько файлов в один:
``` bash
cat part1.txt part2.txt > full.txt
```
**Вывод: парт1 + парт2, и `создается` с этим выводом нью файл**

## Быстро создать файл с текстом прямо из терминала (без открытия nano):
Набираешь команду, пишешь текст с клавиатуры, в конце жмёшь Ctrl + D (сигнал конца файла)
```bash
cat > note.txt # Тут нажимаем enter 
# Дальще просто пишем, после того как написались -- Ctrl + D 
Привет, это первая строка
А это вторая
```
**Вывод: очевидно, то что ты писал**

## Вставить текст с клавиатуры между двумя файлами (символ - означает стандартный ввод)
```bash
cat header.txt - footer.txt > page.txt # enter
# Пишите свой текст, и нажимаете Ctrl + D, как в прошлом примере
```
**Вывод: например в хедер было верх, а в футер, низ,  а после этого выведёт:**
```text
верх
ваш текст
низ
```
**Микро пометка: нажми enter в конце последней строки перед Ctrl + D, иначе в конце файла не будет переноса строки**
# Флаги!

Для примера представим, что у нас есть файл `test.txt`, в котором намешаны пустые строки и табуляция:

```text
Привет


	Строка с табом (буквально TAB, не просто текст БТВ)
Пока
```

1. `-n` -- пронумеровать все строки

Показывает номер каждой строки (удобно, когда нужно быстро сказать напарнику или загуглить ошибку на конкретной строчке конфига).

```bash
cat -n test.txt
```

**Вывод:**

```text
     1  Привет
     2  
     3  
     4  	Строка с табом
     5  Пока
```

2. `-b` -- пронумеровать только строки с текстом

То же самое, что `-n`, но пропускает пустые строки. Код и конфиги с ним читать гораздо приятнее.

```bash
cat -b test.txt
```

**Вывод:**

```text
     1  Привет


     2  	Строка с табом
     3  Пока
```

3. `-s` -- убрать лишние пустые строки

Если в файле 10 пустых строк подряд, флаг сожмёт их в одну. Идеально для чтения длинных и криво отформатированных файлов.

```bash
cat -s test.txt
```

**Вывод:**

```text
Привет

	Строка с табом
Пока
```

4. `-A` -- «рентген» файла (показать все невидимые символы)

Главный флаг для отладки, когда файл выглядит нормально, но скрипт не запускается. Показывает:

- `$` -- конец строки (если перед ним стоит пробел, ты его сразу спалишь).
- `^I` -- нажатие `Tab` (помогает отличить табы от пробелов, например, в Python или YAML).
- `^M$` -- виндовый перенос строки (если видишь это, Linux может ругаться на скрипт).

```bash
cat -A test.txt
```

**Вывод:**

```text
Привет$
$
$
^IСтрока с табом$
Пока$
```
