В Rust есть **три основных вида циклов**. У каждого своя задача.

### 1. Бесконечный цикл - `loop`

Работает бесконечно, пока ты принудительно не остановишь его через `break`.

- **Зачем нужен:** Когда ты не знаешь заранее, сколько раз должен выполниться код (например, игровой цикл, ожидание ввода пользователя в угадайке или обработка сетевых запросов).
    
- **Фишка:** `loop` умеет **возвращать значение** через `break`!
    



```Rust
fn main() {
    let mut counter = 0;

    // loop может возвращать результат в переменную!
    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2; // Выходим из цикла и возвращаем 20
        }
    };

    println!("Результат: {result}"); // Выведет 20
}
```

### 2. Условный цикл - `while`

Выполняет блок кода до тех пор, пока **условие истинно (`true`)**.

- **Зачем нужен:** Когда цикл должен крутиться, пока выполняется какое-то условие.
    
- **Минус:** Если использовать `while` для перебора массива по индексу - это медленно (Rust на каждой итерации проверяет, не вышли ли мы за границы массива) и небезопасно.
    



```Rust
fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{number}!");
        number -= 1;
    }

    println!("ПОЕХАЛИ!");
}
```

### 3. Король итераций - `for`

Самый безопасный, быстрый и idiomatic (правильный) цикл в Rust. Используется для перебора коллекций, диапазонов и итераторов.

- **Зачем нужен:** Пройтись по элементам массива, диапазону чисел и т.д.
    
- **Плюс:** Он **не делает лишних проверок границ** (компилятор оптимизирует его «до небес») и полностью защищает от выхода за пределы массива.
    

#### Пример А: Перебор диапазона чисел



```Rust
fn main() {
    // 1..4 означает от 1 до 3 (4 не включается)
    for number in 1..4 {
        println!("{number}!");
    }

    // 1..=3 означает от 1 до 3 включительно
    // .rev() разворачивает диапазон задом наперёд!
    for number in (1..=3).rev() {
        println!("{number}!");
    }
}
```

#### Пример Б: Перебор элементов массива



```Rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    // Проходим по каждому элементу напрямую!
    for element in a {
        println!("Значение: {element}");
    }
}
```

### 🛑 Управление циклами: `break` и `continue`

1. **`break`** - немедленно вышибает из цикла.
    
2. **`continue`** - пропускает остаток текущего круга и сразу переходит к следующему.
    

#### 🏷 Метки циклов (Loop Labels)

Если у тебя цикл внутри цикла, и тебе надо из самого глубокого `loop` выскочить из **внешнего** - используй метки с одинарной кавычкой `'название`:



```Rust
'outer: loop {
    println!("Вошли во внешний цикл");

    loop {
        println!("Вошли во внутренний цикл");
        
        // Рвём именно ВНЕШНИЙ цикл!
        break 'outer; 
    }
}
```

### 🧠 Краткая шпаргалка: Что и когда юзать?

|**Цикл**|**Когда использовать?**|**Пример**|
|---|---|---|
|**`loop`**|Бесконечный процесс или нужно вернуть значение из `break`.|Игра, меню, ввод до победного (`match`).|
|**`while`**|Повторяем, пока верно простое условие `true/false`.|Счетчик, пока не наступил флаг остановки.|
|**`for`**|Нужно пройтись по диапазону (`1..10`) или коллекции (массиву).|Перебор списка, предметов в инвентаре, кадров.|
