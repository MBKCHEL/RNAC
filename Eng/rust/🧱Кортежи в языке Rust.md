## 2. Кортежи (`tuple`) - Понятные примеры и реальные фичи

Кортеж нужен тогда, когда тебе нужно временно связать несколько разнородных значений, но создавать ради этого отдельную структуру (класс/стракт) лень или нет смысла.

### Пример 1: Мини база данных пользователей

```rust
fn main() {  
    let vanya: (&str, u8, f64) = ("Vanya", 20, 1.9); // 1 кортеж  
  
    let danya: (&str, u8, f64) = ("Danya", 45, 2.0); // 2 кортеж
  
  
    let (name_vanya, age_vanya, height_vanya) = vanya; // распаковка в переменные
  
    let (name_danya, age_danya, height_danya) = danya; // распаковка в переменные
  
    println!("Такие показатели 1 пользователя: Лет: {age_vanya}, Имя: {name_vanya}, рост: {height_vanya} метра"); // Вывод
    println!("Такие показатели 2 пользователя: Лет: {age_danya}, Имя: {name_danya}, рост: {height_danya} метра"); // Вывод
}
```

### Пример 2: Возврат нескольких значений из функции

В отличие от C#, где для возврата нескольких переменных из метода нужно городить `out`-параметры или кортежи, которые нагружают память, в Rust это делается нативно и максимально эффективно.

Rust

```rust
// Функция принимает строку и возвращает кортеж: (статус-код, текст сообщения)
fn parse_data() -> (u16, &'static str) {
    // ...какая-то логика...
    (200, "Успешно обработано") // возвращаем кортеж
}

fn main() {
    let result = parse_data();
    
    // Доступ по индексам через точку
    println!("Код: {}, Ответ: {}", result.0, result.1);
}
```

### Пример 3: Деструктуризация (Распаковка) кортежа

Тебе не обязательно писать `.0`, `.1`. Ты можешь «разобрать» кортеж на отдельные переменные прямо на лету. Это один из главных синтаксических кайфов Rust.

Rust

```rust
fn main() {
    // Кортеж, хранящий IP-адрес и порт сервера
    let server_address: (&str, u16) = ("127.0.0.1", 8080);

    // Распаковываем кортеж в две независимые переменные
    let (ip, port) = server_address;

    println!("Сервер запущен на порту {} по адресу {}", port, ip);
}
```
