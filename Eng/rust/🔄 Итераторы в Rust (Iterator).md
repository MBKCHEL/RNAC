## 🎯 Что это такое

**Итератор** - это «шагатель» по элементам коллекции (массива, вектора и т.д.). Вместо того чтобы вручную считать индексы (`i = 0`, `i = 1`), ты просишь итератор: _«Давай мне по одному элементу, пока они не закончатся»_.

- **Главная фишка:** В Rust итераторы **ленивые** (Zero-Cost Abstractions). Они ничего не делают и не забивают память, пока ты явно не попросишь их пробежаться по элементам.
    

## 🛠 3 Способа получить Итератор

В зависимости от того, что нужно сделать с данными:

1. **`iter()`** - итерирование по **ссылкам** (`&T`). Исходный массив остаётся целым, ты просто «смотришь» на элементы.
    
2. **`iter_mut()`** - итерирование по **мутабельным ссылкам** (`&mut T`). Позволяет изменять элементы на месте.
    
3. **`into_iter()`** - **забирает владение** (`T`). Массив или вектор после этого уничтожается (перемещается).
    

> 💡 Когда ты пишешь `for element in help_print`, Rust под капотом автоматически вызывает `.into_iter()` или `.iter()`.

## ⚡️ Базовый Пример



```Rust
fn main() {
    let music_list = ["track1.mp3", "track2.mp3", "track3.mp3"];

    // Простой перебор через for (авто-итератор)
    for track in music_list.iter() {
        println!("Играет: {track}");
    }
}
```

## 🏎 Крутые методы (Цепочки)

Итераторы можно объединять в мощные цепочки обработки данных без единого цикла `for`:

- **`.map()`** - преобразует каждый элемент.
    
- **`.filter()`** - оставляет только то, что подходит под условие.
    
- **`.collect()`** - собирает результат обратно в новый вектор (`Vec`).
    



```Rust
let numbers = vec![1, 2, 3, 4, 5];

// Берем четные числа и умножаем на 10
let result: Vec<i32> = numbers.into_iter()
    .filter(|x| x % 2 == 0) // останутся 2 и 4
    .map(|x| x * 10)        // станут 20 и 40
    .collect();             // собрали в новый Vec

// result = [20, 40]
```
