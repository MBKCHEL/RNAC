## Константы (`const`) - Понятные примеры реального применения

Константа в Rust - это не просто переменная, которую нельзя изменить. Это значение, которое компилятор **физически вшивает (копирует)** в каждое место кода, где ты его используешь. Они вычисляются _до_ запуска программы.

### Пример 1: Настройка системных ограничений (Размер буфера)

Представь, что ты пишешь сетевую утилиту или парсер файлов. Тебе нужно жестко задать размер читаемого пакета данных в байтах.

Rust

```rust
// Объявляем глобально (вне функций). Тип `usize` идеален для размеров памяти.
const MAX_PACKET_SIZE: usize = 4096; 

fn main() {
    // Мы можем использовать константу для задания размера массива!
    // Обычную переменную `let` сюда подставить нельзя, компилятор не разрешит.
    // в строке [0; MAX_PACKET_SIZE]; 0 - это чем мы заполним массив, а в кортеже 4096 число, значит мы сделаем массив где будет 4096 элементов, а в каждом эелементе будет 0 так как мы сделали авто заполнение нулём
    let buffer: [u8; MAX_PACKET_SIZE] = [0; MAX_PACKET_SIZE]; 
    
    println!("Выделили буфер размером {} байт.", MAX_PACKET_SIZE);
}
```

### Пример 2: Формулы и математические коэффициенты

Константы могут вычисляться на этапе компиляции на основе других констант!

Rust

```rust
const SECONDS_IN_MINUTE: u64 = 60;
const MINUTES_IN_HOUR: u64 = 60;

// Компилятор сам перемножит это ОДИН раз при сборке. В рантайме процессор не будет тратить время на умножение.
const SECONDS_IN_HOUR: u64 = SECONDS_IN_MINUTE * MINUTES_IN_HOUR; 

fn main() {
    println!("Секунд в часе: {}", SECONDS_IN_HOUR);
}
```
