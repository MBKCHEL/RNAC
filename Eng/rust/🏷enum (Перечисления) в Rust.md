## 1. Что такое `enum`?

**`enum` (enumeration / перечисление)** - это тип данных, который позволяет выбрать **один вариант из строго ограниченного списка**.

- **Логика `struct`:** И то, И это (содержит набор полей одновременно).
    
- **Логика `enum`:** ИЛИ то, ИЛИ другое (переменная может содержать **только один** из вариантов в конкретный момент времени).
    

## 2. Фишка Rust: Хранение данных внутри вариантов

В Rust варианты `enum` - это не просто ярлыки, они могут **напрямую хранить данные**, причём разные варианты могут хранить абсолютно разные типы!



```Rust
enum PaymentMethod {
    Card(u64, u16),   // Вариант 1: хранит номер карты (u64) и CVC-
    Crypto(String),   // Вариант 2: хранит адрес кошелька (String)
    Cash,             // Вариант 3: вообще без данных (наличка)
}
```

## 3. Как это работает в коде (Полный пример с `match`)

Главный кайф `enum` раскрывается вместе с конструкцией **`match`**, которая позволяет безопасно «распаковать» данные из варианта.



```Rust
enum PaymentMethod {
    Card(u64, u16),
    Crypto(String),
    Cash,
}

fn process_order(payment: PaymentMethod) {
    // match смотрит, КАКОЙ ИМЕННО вариант пришёл, и вытаскивает данные
    match payment {
        PaymentMethod::Card(number, cvc) => {
            println!("Списываем деньги с карты {} (CVC: {})", number, cvc);
        }
        PaymentMethod::Crypto(wallet) => {
            println!("Ожидаем транзакцию на кошелек: {}", wallet);
        }
        PaymentMethod::Cash => {
            println!("Оплата наличными при получении.");
        }
    }
}

fn main() {
    // Создаем переменные с разным содержимым
    let client_a_pay = PaymentMethod::Card(4400123456789012, 777);
    let client_b_pay =   PaymentMethod::Crypto(String::from("0x71C...89"));

    // Передаем разные варианты в ОДНУ и ту же функцию!
    process_order(client_a_pay);
    process_order(client_b_pay);
}
```

## 4. Главные плюсы и зачем это нужно

1. **Одна функция вместо кучи костылей:** Не нужно писать отдельные функции под каждую жизненную ситуацию (`process_card`, `process_crypto`). Передаёшь один `enum` в одну функцию.
    
2. **Безопасность компилятора:** Конструкция `match` заставляет обработать **все** возможные варианты из `enum`. Если забудешь добавить ветку `Cash`, код просто не скомпилируется.
    
3. **Строгая типизация:** Нельзя случайно передать несуществующий вариант или перепутать формат данных.
