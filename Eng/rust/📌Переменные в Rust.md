### 1. Главный закон Rust: Неизменяемость по дефолту

В отличие от C# и большинства языков, в Расте любая переменная из коробки - это **константа**.

Rust

```rust
let x = 5; 
x = 6; // ❌ ОШИБКА! Компилятор даст по рукам.
```

Чтобы переменную можно было изменить, нужно явно добавить **`mut`** (mutable):

Rust

```rust
let mut x = 5;
x = 6; // ✅ Успешно изменено!
```

### 2. Целые числа (Integers)

В Rust типы чисел называются по их размеру в битах. Очень логично и системно.

| **Тип со знаком (может быть -)** | **Тип без знака (только +)** | **Размер в памяти**                        |
| -------------------------------- | ---------------------------- | ------------------------------------------ |
| `i8`                             | `u8`                         | 8 бит (1 байт)                             |
| `i16`                            | `u16`                        | 16 бит (2 байта)                           |
| `i32` _(дефолт)_                 | `u32`                        | 32 бита (4 байта)                          |
| `i64`                            | `u64`                        | 64 бита (8 байт)                           |
| `i128`                           | `u128`                       | 128 бит (16 байт)                          |
| `isize`                          | `usize`                      | Зависит от архитектуры ПК (32 или 64 бита) |

> 📌 **Важно для геймдева:** `usize` почти всегда используется для **индексов массивов** и циклов, потому что он равен размеру указателя в памяти твоего ПК.

### 3. Дробные числа (Floats)

Тут всё просто, их всего два вида (в C# это `float` и `double`):

- `f32` - одинарная точность (то, что в Unity используется везде для координат и физики).
    
- `f64` _(дефолт)_ - двойная точность (более точные расчёты).
    

Rust

```rust
let distance: f32 = 10.5;
```

### 4. Логический тип и Символы

- **Булевы (`bool`):** Традиционные `true` или `false`. Занимают 1 байт.
    
- **Символы (`char`):** Одиночный символ в **одинарных кавычках**. В Rust `char` весит аж 4 байта, потому что поддерживает вообще все символы Юникода (даже эмодзи!).
    

Rust

```rust
let is_running: bool = true;
let icon: char = '🦀'; // Да, это валидный char!
```

### 5. Текстовый ад: Строки (Введение)

Строки в Rust - это отдельная боль новичков, потому что их... несколько видов. Но для базы тебе нужно знать два главных:

1. **`&str` (Строковый срез / литерал):**
    
    Это текст, зашитый намертво в саму программу. Он неизменяемый. Когда ты пишешь текст в кавычках - это `&str`.
    
    Rust
    
    ```rust
    let status = "Alive"; // Тип: &str
    ```
    
2. **`String` (Динамическая строка):**
    
    Это полноценная строка, которая создаётся в куче (heap). Её можно расширять, изменять, дописывать в неё символы.
    
    Rust
    
    ```rust
    let mut player_name = String::from("Vanya"); // Создали String
    player_name.push_str(" _Dev"); // Изменили строку
    ```
    

### 6. Фишка Rust: Затенение (Shadowing)

В Rust можно объявить новую переменную с **точно таким же именем**, как у старой. Это называется затенением. Старая переменная как бы «умирает», а её место занимает новая, причём она может быть даже _другого типа_!

Rust

```rust
let spaces = "   "; // Это строка (&str)
let spaces = spaces.len(); // Теперь spaces - это число (usize), равное 3!
```

_Зачем?_ Чтобы не придумывать тупые имена типа `spaces_str`, `spaces_int`, а красиво переиспользовать одну переменную в рамках одного блока кода.
