	`match` идеально подходит для обработки выбора игрока (`1`, `2`, `3`), когда веток сюжета много.

- `|` - означает **ИЛИ** (несколько выборов ведут к одному результату).
    
- `_` - означает **«любой другой ввод»** (защита от дебила, если игрок ввёл в консоль случайную цифру или букву).
    

### Вкусный вступительный пример:

```rust
#[derive(Debug)]
enum UsState {
    Alaska,
    Alabama,
    California,
}

enum Coin {
    Penny,
    Quarter(UsState), // Четвертак, внутри которого лежит штат
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        // Распаковываем штат из четвертака прямо в переменную state:
        Coin::Quarter(state) => {
            println!("Вау, достали четвертак из штата {:?}!", state);
            25
        }
    }
}

fn main() {
    // 1. Создаём монету со штатом Аляска
    let my_coin = Coin::Quarter(UsState::Alaska);

    // 2. Передаём её в функцию
    let cents = value_in_cents(my_coin);

    println!("Номинал монеты: {} центов", cents);
}
```
### Пример 1, спрашиваем у пользователя какой сейчас месяц и он выводит какое время года: 

``` rust
use std::io;  
  
fn main() {  
    let seasons = ["Зима", "Весна", "Лето", "Осень" ];  
  
    let mut user_month = String::new();  
  
    io::stdin().read_line(&mut user_month)  
        .expect("Failed to read line");  
  
    let user_month = user_month.trim();  
  
    match user_month.to_lowercase().as_str() {  
        "январь" | "декабрь" | "февраль"  => println!("{}", seasons[0]),  
        "март" | "апрель" | "май" => println!("{}", seasons[1]),  
        "июнь" | "июль" | "август" => println!("{}", seasons[2]),  
        "сентябрь" | "октябрь" | "ноябрь" => println!("{}", seasons[3]),  
        _ => println!("Не известный месяц"),  
    }  
}
```

### Пример 2: Обработка выбора в меню диалога (с оператором `|`)



```Rust
let dialog_choice = 3;

match dialog_choice {
    1 => println!("Вы говорите: «Сдавайся!». Бандит лишь смеется в ответ."),
    2 | 3 => {
        // Сработает, если игрок ввёл 2 ИЛИ 3
        println!("Вы решаете промолчать или отойти назад. Атмосфера накаляется.");
    }
    _ => println!("Вы замешкались и не успели ничего сделать. Время упущено."),
}
```

### Пример 3: Проверка 2-х условий в `match` (Выбор + Характер персонажа)

Чтобы проверить сразу два условия (например, какую фразу выбрал игрок + какой у него сейчас характер: «добрый» или «злой»), мы объединяем их в круглые скобки `(выбор, характер)`.



```Rust
let choice = 1;
let alignment = "злой";

match (choice, alignment) {
    (1, "добрый") => println!("Вы вежливо просите стражника пропустить вас. Он улыбается."),
    (1, "злой") => println!("Вы сквозь зубы приказываете отойти. Стражник хватается за меч."),
    (2, _) => println!("Вы просто проходите мимо, проигнорировав стражу."), 
    // Заглушка `_` выше означает, что при выборе 2 характер персонажа вообще не важен
    _ => println!("Вы ввели что-то не то, стражник подозрительно прищурился."),
}
```

### Пример 4: Проверка условий «на лету» внутри `match` (Match Guards)

Иногда внутри `match` нужно проверить числовой параметр (например, сколько у игрока денег на покупку инфы в таверне). Для этого прямо после варианта пишется `if`.



```Rust
let choice = 3; // Игрок выбирает купить секретную карту за 50 монет
let gold = 45;

match choice {
    3 if gold >= 50 => println!("Вы отдаете 50 монет и забираете карту."),
    3 if gold < 50 => println!("Трактирщик прячет карту: «Приходи, когда разбогатеешь!»"),
    _ => println!("Вы просто пьете квас и слушаете слухи."),
}
```
## 5. Обычный `match`

Используется как замена длинным `if / else`. Он сравнивает значение переменной со списком вариантов.

- `=>` - отделяет вариант от действия.
    
- `_` - обязательный финальный вариант для всех остальных случаев, которые не подошли под верхние цифры.
    

### Пример для новеллы:



```Rust
let item = "ключ"; // Что игрок достал из инвентаря

match item {
    "монета" => println!("Вы бросили монету в фонтан."),
    "ключ" => println!("Вы открыли замок."),
    _ => println!("Этот предмет здесь бесполезен."),
}
```
