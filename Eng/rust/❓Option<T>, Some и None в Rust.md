### 1. Главная идея

В Rust **нет понятия `null` / `nullptr`**.

Вместо него используется встроенный enum - **`Option<T>`**. Он явно заставляет тебя обрабатывать случаи, когда значение есть, и когда его нет.



```Rust
enum Option<T> {
    Some(T), // Значение ЕСТЬ (оборачивает данные типа T)
    None,    // Значения НЕТ
}
```

### 2. Зачем это нужно?

- **Безопасность:** Компилятор не даст использовать данные из `Option`, пока ты явно их оттуда не достанешь. Забыть проверить на `null` физически невозможно.
    
- **Предсказуемость:** Сигнатура функции сразу говорит, может ли она вернуть «пустоту».
    

### 3. Базовый пример



```Rust
fn find_number(flag: bool) -> Option<i32> {
    if flag {
        Some(42) // Успех: вернем число
    } else {
        None     // Ничего не нашли
    }
}
```

### 4. Способы работы с `Option` (как вытащить значение)

#### A. Через `match` (полный контроль)

Берет под контроль оба варианта развития событий.



```Rust
fn main() {
    match find_number(true) {
        Some(val) => println!("Нашли число: {val}"),
        None => println!("Ничего не нашли!"),
    }
}

// ВОТ ОНА, ФУНКЦИЯ!
fn find_number(flag: bool) -> Option<i32> {
    if flag {
        Some(42)
    } else {
        None
    }
}

```

#### B. Через `if let` (быстро достать `Some`)

Используется, если обработка `None` не нужна.



```Rust
if let Some(val) = find_number(true) {
    println!("Число: {val}");
}
```

#### C. Метод `.unwrap_or()` (с дефолтным значением) - _Безопасно_

Если внутри `Some`, вернет значение. Если `None` - вернет переданный дефолт.



```Rust
let number = find_number(false).unwrap_or(0); // вернет 0
```

#### D. Методы `.unwrap()` и `.expect()` - _Опасно!_

Достают значение напрямую, **НО если там `None`, программа упадет в `panic!`**.



```Rust
let val1 = find_number(true).unwrap(); // Вернет 42
let val2 = find_number(false).expect("Ожидали число!"); // Упадет с твоей ошибкой
```

### 5. Краткая шпаргалка

|**Понятие / Метод**|**Что делает**|
|---|---|
|**`Some(v)`**|Обертка над существующим значением `v`.|
|**`None`**|Обозначение отсутствия значения.|
|**`if let Some(x) = opt`**|Выполняет блок кода, только если внутри `Some`.|
|**`.unwrap_or(default)`**|Безопасно достает значение или подставляет `default`.|
|**`.is_some()` / `.is_none()`**|Возвращает `true`/`false` для проверки состояния.|
