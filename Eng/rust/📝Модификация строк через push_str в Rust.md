В Rust строки типа `String` можно динамически расширять (дописывать в них текст), но только если переменная создана как изменяемая (`mut`).

### 🛠️ Метод `.push_str()`

Этот метод берет твою строку и намертво прилепляет к её концу другой текстовый слайс `&str`.



```Rust
fn main() {
    // 1. Обязательно пишем mut, иначе строку нельзя будет изменить
    let mut item = String::from("Топор"); 
    
    // 2. Дописываем текст в конец строки
    item.push_str(" Кровяной"); 

    println!("{item}"); // Выведет: "Топор Кровяной"
}
```

### 🪓 В чём разница между `push_str` и `push`?

В Расте для строк есть два похожих метода, не перепутай их в коде:

- **`.push_str("Текст")`** - добавляет целый **строковый слайс** (текст в двойных кавычках).
    
- **`.push('🪓')`** - добавляет всего **один одиночный символ** (ограняется строго ОДИНАРНЫМИ кавычками `' '`).
    


### Как юзаеться метод push:

```Rust
let mut craft = String::from("Крафт");
craft.push_str(" оружия"); // Добавили строку
craft.push('!');           // Добавили один символ
```
