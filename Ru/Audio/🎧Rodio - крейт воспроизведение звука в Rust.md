## 🎯 Что это такое и зачем нужно

**Rodio** - это самая популярная аудио-библиотека в экосистеме Rust. Она берёт на себя всю работу с аудиокартой и звуковыми потоками системы, позволяя легко загружать и проигрывать файлы (`.mp3`, `.wav`, `.flac`, `.ogg`).

- **Главный плюс:** Работает «из коробки» на Linux, Windows и macOS без необходимости писать низкоуровневый код под каждый C-библиотечный звуковой сервер (ALSA, PulseAudio, PipeWire).
    

## 🧱 Главные Сущности (Как всё устроено)

Вся работа с `rodio` держится на 3 главных элементах:

1. **`OutputStream` (Звуковой Выход)** - связь с вашей звуковой картой/динамиками. Он должен жить всё время, пока играет музыка. Если его дропнуть (удалить из памяти), звук мгновенно исчезнет.
    
2. **`Sink` (Управляющий Плеер / «Раковина»)** - главный орган управления. В него «заливают» звук, и через него делают паузу, меняют громкость, останавливают или мотают трек.
    
3. **`Decoder` (Декодер)** - читает аудиофайл из диска (или памяти) и превращает сжатые байты (`.mp3` / `.ogg`) в сырой поток аудио-семплов.

## ⚙️ Базовый Шаблон Кода



```Rust
use rodio::{Decoder, OutputStream, Sink};
use std::fs::File;
use std::io::BufReader;

fn main() {
    // 1. Инициализируем аудиовыход системы
    // _stream_handle нужен для связи с аудиокартой
    let (_stream, stream_handle) = OutputStream::try_default().unwrap();

    // 2. Создаем player (управляющий плеер)
    let player = Sink::try_new(&stream_handle).unwrap();

    // 3. Открываем файл и оборачиваем в BufReader (для быстрой вычитки)
    let file = File::open("MDMA.mp3").unwrap();
    let reader = BufReader::new(file);

    // 4. Декодируем аудиофайл
    let source = Decoder::new(reader).unwrap();

    // 5. Отправляем трек в Sink и начинаем воспроизведение
    sink.append(source);

    // 6. Ждем, пока трек доиграет (иначе программа сразу завершится)
    sink.sleep_until_end();
}
```

## 🎛 Основные Команды Управления (`Sink`)

Всё управление воспроизведением происходит через методы `Sink`:

|**Метод**|**Что делает**|**Пример**|
|---|---|---|
|**`sink.play()`**|Снять с паузы / продолжить играть|`sink.play();`|
|**`sink.pause()`**|Поставить на паузу|`sink.pause();`|
|**`sink.is_paused()`**|Проверить, стоит ли на паузе (`bool`)|`if sink.is_paused() { ... }`|
|**`sink.set_volume(val)`**|Изменить громкость (`1.0` = 100%, `0.5` = 50%, `2.0` = 200%)|`sink.set_volume(0.8);`|
|**`sink.volume()`**|Узнать текущий уровень громкости (`f32`)|`let vol = sink.volume();`|
|**`sink.stop()`**|Полностью остановить и очистить очередь|`sink.stop();`|
|**`sink.empty()`**|Проверить, пуста ли очередь треков (`bool`)|`if sink.empty() { ... }`|
|**`sink.append(source)`**|Добавить следующий трек в очередь|`sink.append(next_source);`|

## ⚠️ Важные Нюансы и Грабли

1. **Не давай `OutputStream` сгореть:**
    
    
    ```Rust
    // ОШИБКА: _stream удалится в конце функции, и звук сразу пропадет!
    fn play_sound() {
        let (_stream, handle) = OutputStream::try_default().unwrap();
        let sink = Sink::try_new(&handle).unwrap();
        // ...
    } 
    ```
    
    _Решение:_ Переменную `_stream` (или весь поток) нужно хранить в главной структуре приложения на протяжении всей жизни программы.
    
2. **Работа с громкостью (`f32`):**
    
    Громкость в `rodio` задается дробным числом `f32`.
    
    - `0.0` - полная тишина.
        
    - `1.0` - стандартная громкость (100%).
        
    - При регулировке кнопочками `+` и `-` удобно прибавлять/отнимать шагом в `0.1` (`10%`).
        
3. **Очередь воспроизведения (Playlist):**
    
    Если вызвать `sink.append(track1)` и сразу `sink.append(track2)`, `rodio` не наложит их друг на друга, а воспроизведёт **последовательно**: сначала первый, потом второй.
