### 1. Объявление и простейший пример

- **Ключевое слово:** `fn`
    
- **Именование:** `snake_case` (все буквы маленькие, слова через подчёркивание).
    
- **Типы параметров:** Для каждого входящего аргумента **обязательно** явно писать тип.
    



```Rust
// Простой понятный пример: функция считает урон
fn deal_damage(health: i32, damage: i32) -> i32 {
    health - damage // Возвращаем остаток ХП (без точки с запятой в конце!)
}

fn main() {
    let current_hp = deal_damage(100, 25);
    println!("Осталось ХП: {current_hp}"); // Выведет 75
}
```

### 2. Выражения (Expressions) vs Инструкции (Statements)

В Rust **всё строится на возврате значений**.

- **Инструкция (Statement):** Просто действие. Всегда заканчивается `;` и ничего не возвращает.
    
- **Выражение (Expression):** Вычисляет и отдаёт результат. **Заканчивается БЕЗ `;`**.
    



```Rust
fn plus_one(x: i32) -> i32 {
    x + 1 // Нет ';' - значит это выражение, функция вернёт x + 1
}

// ❌ ТИПИЧНАЯ ОШИБКА:
fn plus_one_broken(x: i32) -> i32 {
    x + 1; // Поставил ';' - превратил в инструкцию! Функция теперь возвращает ничего (юнит-тип `()`).
}
```


## И ещё классный пример к этой мини теме

```Rust
fn five() -> i32 { // Указываю, что функция ОБЯЗАНА вернуть число типа i32
    5 // Возвращаю 5 (Важно: ';' НЕ ставлю, чтобы это было выражение!)
}

fn main() {
    let x = five(); // Вызываю функцию и записываю ВОЗВРАЩЁННЫЙ результат (5) в переменную x

    println!("{x}"); // Выведет 5!
}
```

### 3. Как передавать переменные в функции (Самое главное!)

В Rust есть 3 способа «дать» переменную другой функции:

#### 🟢 Способ 1: Отдать насовсем (Передача владения / Move)

Если тип хранит данные в куче (например, `String`), то при передаче в функцию старая переменная **умирает** и больше недоступна в `main()`.



```Rust
fn print_message(text: String) { // принимаем её
    println!("Сообщение: {text}"); 
} // Здеcь `text` удаляется из памяти!

fn main() {
    let my_str = String::from("Привет");
    print_message(my_str); // Отдаём переменную
    
    // ❌ ОШИБКА! my_str больше не существует, её отдала функция выше!
    // println!("{my_str}"); 
}
```

#### 🟡 Способ 2: Дать «погонять» / Почитать (Немутабельная ссылка `&`)

Если функция должна просто **посмотреть** на данные, не меняя их, передавай ссылку через `&`. Владение остаётся у `main()`.



```Rust
fn print_length(text: &String // Получаем её) {
    println!("Длина строки: {}", text.len());
} // Ссылка `text` уходит из области видимости, но сама строка не удаляется!

fn main() {
    let my_str = String::from("Привет, Раст!");
    print_length(&my_str); // Передаём ссылку с помощью `&`
    
    // ✅ ВСЁ ОК! Переменная осталась жива в main()
    println!("Строка всё ещё тут: {my_str}"); 
}
```

#### 🔴 Способ 3: Дать «погонять и изменять» (Мутабельная ссылка `&mut`)

Если функция должна **изменить** переменную, передаём мутабельную ссылку `&mut`. Переменная в `main()` изначально тоже должна быть `mut`.

``` Rust
fn add_exclamation(text: &mut String) {
    text.push_str("!!!"); // Изменяем оригинал по ссылке
}

fn main() {
    let mut my_str = String::from("Привет");
    
    add_exclamation(&mut my_str); // Передаём мутабельную ссылку `&mut`
    
    // ✅ Результат изменился прямо внутри my_str!
    println!("{my_str}"); // Выведет: "Привет!!!"
}
```

### 💡 Короткая шпаргалка-памятка:

1. Нужно просто отдать аргумент `i32`, `bool`, `f64`? → Передавай как есть (числа банально копируются).
    
2. Функция должна только **прочитать** `String` / массив / структуру? → Используй `&T` (ссылку).
    
3. Функция должна **изменить** `String` / массив / структуру? → Используй `&mut T` и сделай переменную `mut`.
    
4. Хочешь вернуть результат без `return`? → Убери `;` в последней строчке функции!
