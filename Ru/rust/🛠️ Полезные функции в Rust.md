- # len(); - выводит количество БАЙТОВ. Именно байтов, а не символов, пример в коде: 
```rust
  fn main() {  
    let x = "ggg";  // Задаём значение переменной
      
    let x = x.len(); // Затеняем переменную х и выводим количевство БАЙТОВ
  
    println!("{x}");  // Выводит 3
}
``` 
## Главный прикол len(); он выводит БАЙТЫ, если например я напишу переменную: let X = "Кот"; Оно выводит, не 3, а 6, потому-что кириллица занимает 2 байта ОЗУ. 


- # `as_bytes()` в Rust

> **Главная суть:** Метод `as_bytes()` берет строку (`String` или `&str`) и возвращает **срез байтов** (`&[u8]`). Он не копирует текст, а просто дает посмотреть на то, из чего этот текст состоит в памяти.

### 1. Зачем вообще переводить строку в байты?

Для человека строка - это набор букв (`'h'`, `'e'`, `'l'`).

Для компьютера строка - это просто последовательность чисел (байтов) в кодировке **UTF-8**.

- Буква `'h'` в памяти - это число `104`.
    
- Буква `'e'` - это `101`.
    
- Пробел `' '` - это число `32`.
    

Проверять байты в цикле для Rust **в сотни раз быстрее**, чем разбирать сложные символ-за-символом структуры.

### 2. Простой пример:



```Rust
fn main() {
    let text = "hello";
    
    // Переводим строку в срез байтов
    let bytes = text.as_bytes(); 

    println!("{:?}", bytes); 
    // Выведет: [104, 101, 108, 108, 111]
}
```

### 3. Что за фигня `b' '` (Байтовый литерал)?

В коде выше ты видел: `if item == b' '`.

Буква `b` перед кавычками превращает символ в его числовой байтовый код:

- `' '` - это символ «пробел».
    
- `b' '` - это **байт** (число `32`), обозначающий пробел.
    

Мы перевели строку в байты (`as_bytes()`), поэтому и сравнивать элементы мы должны **с байтами** (`b' '`), а не с обычными буквами!

### 💡 Итог в трёх словах:

1. `s.as_bytes()` $\rightarrow$ превращает текст в список чисел-байтов `[104, 101, 108...]`.
    
2. `b' '` $\rightarrow$ байтовый код пробела (число `32`).
    
3. Компьютер быстро сравнивает **число с числом**, за счет чего поиск пробела работает мгновенно!

- # \t, и \n
  \t это табуляция, а \n это переход на новую строку, то бишь:

 Это \n
```rust
fn main() {
    println!("Hello\n, world!");
}
```
Выводит: 

```bash
Hello
, world!
```

Это \t
```Rust
fn main() {
    println!("Hello");
    println!("\tworld!");
}
```
Выводит:
```Bash
Hello
        world!

```
