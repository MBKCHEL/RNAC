**Суть:** Многопоточность - это когда вместо одного рабочего ты нанимаешь бригаду, чтобы загрузить все ядра процессора и сделать работу в разы быстрее.

### 1. Rayon: Параллелизм в 1 строчку (Data Parallelism)

**Что это:** Крейт, который сам режет огромный массив или диапазон на куски и раскидывает их по всем ядрам CPU.

- **Аналогия:** Вместо того чтобы один человек мыл 100 тарелок по очереди, приходят 12 человек и моют каждый свою стопку.
    

```Rust
use rayon::prelude::*; // Подключаем магию Rayon

fn main() {
    // .into_par_iter() делает итератор параллельным
    let sum: u128 = (1..1_000_000_000_u128)
        .into_par_iter() // <- ВСЯ МАГИЯ ЗДЕСЬ
        .map(|n| n * 2)   // Выполняется параллельно на всех ядрах
        .sum();

    println!("Сумма: {}", sum);
}
```

- **Главный плюс:** Не нужно вручную создавать и контролировать потоки.
    
- **Где юзать:** Векторы, массивы, тяжелые циклы, парсинг множества файлов.
    

### 2. `std::thread::spawn`: Создание отдельного потока

**Что это:** Низкоуровневый запуск задачи на другом ядре через стандартную библиотеку.

```Rust
use std::thread;
use std::time::Duration;

fn main() {
    // Spawn нанимает фонового рабочего
    let handle = thread::spawn(|| {
        thread::sleep(Duration::from_millis(500)); // Пауза (поток «спит»)
        println!("Поток доделал работу!");
    });

    println!("Главный поток работает дальше...");

    // join() замораживает главный поток, пока фоновый не закончит
    handle.join().unwrap(); 
}
```

- **`thread::sleep(...)`** - ставит поток на паузу, чтобы он не грузил ядро процессора на 100% впустую.
    
- **`handle.join()`** - ждёт завершения потока (без этого программа завершится раньше, чем поток успеет сработать).
    

### 3. Передача данных между потоками

Разные потоки живут в изоляции. Чтобы передавать или делить данные, используют 3 инструмента:

#### А. Ключевое слово `move` (Отдать владение)

Если поток использует внешнюю переменную, он должен **забрать её себе навсегда**.

```Rust
let data = vec![1, 2, 3];

// move забирает data внутрь потока
thread::spawn(move || {
    println!("{:?}", data);
});
```

#### Б. Каналы `mpsc` (Рация между потоками)

Работает по принципу: _"Один пишет/отправляет, другой слушает/принимает"_.



```Rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();
    let x = "21";

    // Создаем поток
    let handle = thread::spawn({
        // Клонируем передатчик специально для этого потока
        let tx = tx.clone();
        move || {
            tx.send("Данные из потока").unwrap();
            println!("Внутри потока переменная x = {}", x);
        }
    });

    // Отправляем сообщение из основного потока
    tx.send(x).unwrap();

    // ВАЖНО: Дропаем оригинальный tx в main.
    // Теперь живым остался только tx внутри потока.
    // Когда тот поток завершится, канал закроется полностью.
    drop(tx);

    // Удобный цикл: сам ждет и читает ВСЕ сообщения из канала
    for message in rx {
        println!("Получено: {}", message);
    }

    handle.join().unwrap();
}

```

#### В. `Arc<Mutex<T>>` (Общая память под замком)

Если 10 потоков должны одновременно менять **одну и ту же** переменную.

- **`Mutex<T>`** - сейф с замком. Изменить данные внутри может только 1 поток одновременно.
    
- **`Arc<T>`** - умный указатель, который позволяет нескольким потокам одновременно держать ссылку на этот сейф.
    

```Rust
use std::sync::{Arc, Mutex};
use std::thread;

let counter = Arc::new(Mutex::new(0)); // Сейф со счётчиком 0
let counter_clone = Arc::clone(&counter);

thread::spawn(move || {
    let mut num = counter_clone.lock().unwrap(); // Открываем замок
    *num += 1;                                    // Меняем значение
}); // Замок автоматически закрывается при выходе из {}
```

### 💡 Главные шпаргалки для головы

- **Обычный итератор:** `.into_iter()` → 1 ядро.
    
- **Параллельный итератор:** `.into_par_iter()` → Все ядра на 100%.
    
- **`Send`:** Маркер Rust, что тип можно безопасно перекинуть в другой поток.
    
- **`Sync`:** Маркер Rust, что к типу можно безопасно обращаться из разных потоков по ссылке.
    
- **Data Race:** В Rust **невозможен** благодаря `borrow checker`. Code or compiler error - никаких скрытых багов в рантайме.
