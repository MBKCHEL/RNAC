### 🔑 Главное правило ввода в Rust

**Любой ввод с клавиатуры Rust всегда читает как текст (строку).** Чтобы работать с данными дальше, нам нужны изменяемый буфер `String` и цепочка методов для очистки и преобразования.

### 1. Затенение (Shadowing) и обработка ошибок (`match`)

В Rust можно объявлять новую переменную с **тем же именем**, что и у старой. Это называется **затенением** (Shadowing). Это идеально подходит, чтобы преобразовать строковый `guess` в числовой `guess` без придумывания имен вроде `guess_str` и `guess_num`.

#### Вариант А: Затенение с ядрёной ошибкой (`expect`)

Если юзер введёт буквы - программа упадет с твоим текстом ошибки (паника).



```Rust
let mut guess = String::new();
std::io::stdin().read_line(&mut guess).expect("Не удалось прочитать строку");

// Объявляем новую переменную guess типа u32, перекрывая старую строку:
let guess: u32 = guess.trim().parse()
    .expect("Пожалуйста, напишите число!!!");
```

#### Вариант Б: Затенение с обработкой ошибок (`match` из 2-й главы)

Если юзер введёт буквы - программа не упадёт, а проигнорирует ошибку и попросит ввод заново!



```Rust
loop {
    println!("Введи число:");

    let mut guess = String::new();
    std::io::stdin().read_line(&mut guess).expect("Ошибка чтения");

    // Затенение + match
    let guess: u32 = match guess.trim().parse() {
        Ok(num) => num,      // Распарсил? Отлично, в guess запишется num, идем К СТРОКЕ 14!
        Err(_) => continue,  // Ошибка? Перескакиваем сразу НА СТРОКУ 2 (в начало цикла)!
    };

    println!("Ты ввел число: {guess}");
    // ... дальше сравнение через match guess.cmp(&secret_number)
}
};
```


#### Вариант В: обычный ввод в консоль
```rust
use std::io;  
  
fn main() {  
    let mut x = String::new();  
  
    io::stdin().read_line(&mut x)  
        .expect("Error reading line");
        
    println!("Ты ввёл: {x}");  
}
```
### 2. Преобразование через Turbofish 🐟 (`::<Тип>`)

Вместо явного указания типа слева (`let x: i32 = ...`), можно прикрепить тип прямо к методу `.parse()` с помощью синтаксиса **«турбо-рыбы»** - `::<Тип>`.



```Rust
use std::io;

fn main() {
    let mut num1 = String::new();
    let mut num2 = String::new();

    println!("Введите 1-е число:");
    io::stdin().read_line(&mut num1).expect("Ошибка чтения");

    println!("Введите 2-е число:");
    io::stdin().read_line(&mut num2).expect("Ошибка чтения");

    // ТУРБО-РЫБА В ДЕЛЕ:
    // Тип переменной слева писать НЕ НАДО, Rust сам всё поймёт!
    let num_int1 = num1.trim().parse::<i32>().unwrap();
    let num_int2 = num2.trim().parse::<i32>().unwrap();

    let result = num_int1 + num_int2;
    println!("Сумма: {result}");
}
```

#### 🛠 Разбор фишек:

- **`.parse::<i32>()`** - принудительно указывает методу `.parse()`, в какой именно тип трансформировать строку (`i32`, `u32`, `f64`, `bool`).
    
- **`.unwrap()`** - быстрый «взлом» результата. Возвращает значение, если всё ок. Если внутри ошибка - программа моментально падает.
    
- **`.expect("msg")`** - то же самое, что `.unwrap()`, но при падении выводит твоё понятное сообщение.
    

### 3. Парсинг Булевого типа (`bool`) через Turbofish

Турбо-рыба идеально парсит и логические значения (`true` / `false`):



```Rust
use std::io;

fn main() {
    let mut input = String::new();
    println!("Введи true или false:");

    io::stdin().read_line(&mut input).expect("Ошибка чтения");

    // Приводим к нижнему регистру и парсим в bool с помощью ::<bool>()
    let likes_rust = input.trim().to_lowercase().parse::<bool>().unwrap();

    match likes_rust {
        true => println!("Наш человек! 🦾 🦀"),
        false => println!("Ничего, скоро полюбишь. 😉"),
    }
}
```

### 4. Приведение типов через `as` (Casting)

Rust никогда не складывает разные типы автоматически (например, `i16` и `u8`). Их нужно приводить вручную через оператор `as`.



```Rust
let num1: i16 = 15; 
let num2: u8 = 15; 

// Без `as i16` компилятор выдаст ошибку Mismatched Types
let result: i16 = num1 + (num2 as i16); 
```

#### ⚠️ Железное правило кастинга:

**Всегда приводи меньший тип к большему** (например, из `u8` в `i16` или из `i32` в `f64`).

> **Важно:** Если попытаться сжать больший тип в меньший (например, сделать `1000_i32 as u8`), Rust не выдаст ошибку компиляции, но число «обрежется» (произойдёт переполнение/overflow), и ты получишь багнутые, искажённые данные.

### 🧠 Итоговая шпаргалка-алгоритм (Запомнить как отче наш)

1. **Создание буфера:** `let mut input = String::new();`
    
2. **Чтение строки:** `io::stdin().read_line(&mut input).expect("...");`
    
3. **Очистка от Enter (`\n` / `\r\n`):** `input.trim()`
    
4. **Конвертация (Вариант 1 - Затенение с типом слева):** `let input: u32 = input.trim().parse().unwrap();`
    
5. **Конвертация (Вариант 2 - Стиль Turbofish 🐟):** `let input = input.trim().parse::<u32>().unwrap();`
    
6. **Кастинг чисел:** Приводим через `as` только снизу вверх (`u8` ➔ `u16` ➔ `i32`).
