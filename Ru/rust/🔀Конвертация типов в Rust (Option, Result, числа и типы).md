Конвертация в Расте - это превращение одного типа данных в другой. Позволяет избегать громоздких `match` и аккуратно обрабатывать ошибки.

### 1. Превращение `Result` в `Option` (`.ok()`)

Используется, когда результат операции с ошибкой (`Result<T, E>`) нужно превратить в обычный `Option<T>` (ошибка превращается в `None`).



```Rust
let input = "100"; // Корректный ввод
let parsed: Option<i32> = input.parse().ok(); // вернёт Some(100)

let bad_input = "abc"; // Ошибка парсинга
let parsed_bad: Option<i32> = bad_input.parse().ok(); // вернёт None
```

- **Зачем:** Идеально для парсинга строк/ввода от игрока, когда нам важен только факт наличия валидного числа, а сама ошибка не интересна.
    

### 2. Превращение `Option` в `Result` (`.ok_or()`)

Наоборот: превращает `Option<T>` в `Result<T, E>`, если нужно выбросить понятную ошибку вместо пустого `None`.



```Rust
let player_name: Option<&str> = None;

// Если None - превращается в Err с нашим сообщением
let result = player_name.ok_or("Имя игрока не задано!");
// result станет: Err("Имя игрока не задано!")
```

### 3. Преобразование внутри `Option` (`.map()`)

Позволяет применить функцию к значению внутри `Some`, не трогая `None`.



```Rust
fn plus_one(x: Option<i32>) -> Option<i32> {
    x.map(|i| i + 1)
}

let hp = Some(99);
let new_hp = plus_one(hp); // вернёт Some(100)

let no_hp = None;
let result = plus_one(no_hp); // вернёт None
```

### 4. Конвертация ссылок в значения (`.copied()` и `.cloned()`)

При поиске в коллекциях или словарях (`HashMap`) Раст возвращает ссылки (`Option<&T>`). Чтобы получить само значение, используются методы `.copied()` или `.cloned()`.

- **`.copied()`** - для простых типов (`i32`, `bool`, `f32`), которые реализуют трейт `Copy`.
    
- **`.cloned()`** - для сложных типов (`String`, `Vec`), которые требуют явного клонирования.
    



```Rust
let scores = vec![10, 20, 30];

// .find() возвращает Option<&i32>
// .copied() превращает Option<&i32> в Option<i32>
let found: Option<i32> = scores.iter().find(|&&x| x == 20).copied(); 
```

### 5. Приведение базовых типов (`as`)

Для преобразования числовых типов используется ключевое слово `as`.



```Rust
let damage: f32 = 45.7;
let final_damage = damage as i32; // 45 (дробная часть отбрасывается)

let level: u8 = 50;
let level_i32 = level as i32; // Преобразование в более широкий тип
```

> **Важно:** При преобразовании из больших типов в меньшие с помощью `as` (например, `i32 as u8`) может произойти переполнение значения!
