### 1. Главная идея

В Rust фигурные скобки `{ ... }` - это не просто разделитель кода, а **выражение, которое возвращает значение**.



```Rust
let result = {
    let a = 10;
    let b = 20;
    a + b // 👈 НЕТ точки с запятой! Блок вернёт 30
};

println!("{result}"); // Выведет 30
```

## Ещё пример: 
```Rust
fn main() {  
    let x = 5;// Делаем переменую Х
  
    let y ={  
        let x = 3;  // В этом блоке переменая Х временно затеняеться
        x + 1  
    }; // В конце переменная Х умирает, но она возрождаеться в переменой y, и наша 1 переменая Х появляеться обратно.
  
    println!("The value of y is: {}", y);  
}
```


### 2. Золотое правило точки с запятой `;`

- **Без `;` в конце блока:** Блок «выплёвывает» значение наружу в переменную.
    
- **С `;` в конце блока:** Значение «съедается», и блок возвращает ничего (пустой тип `()`).
    



```Rust
// ❌ Ошибка логики (забыли убрать ';'):
let result = {
    let a = 10;
    a + 5; // Поставили ';'! Теперь result равен () вместо 15
};
```

### 3. Изоляция и защита от мусора (Scope)

Все переменные, созданные внутри `{ ... }`, **умирают сразу при выходе из скобок**.

Это нужно, чтобы вычислять сложные штуки, не засоряя оперативку и имена переменных в основной функции.



```Rust
fn main() {
    let final_damage = {
        let base = 50;
        let crit_multiplier = 2;
        base * crit_multiplier
    };

    // ❌ Тут `base` и `crit_multiplier` УЖЕ НЕ СУЩЕСТВУЮТ!
    // println!("{base}"); // Ошибка компиляции!

    // ✅ Доступен только чистый результат:
    println!("Урон: {final_damage}"); // 100
}
```

### 4. Затенение (Shadowing) внутри блоков

Если переобъявить переменную с таким же именем внутри `{ ... }`, она «перекроет» внешнюю, но **только пока код находится внутри этих скобок**.



```Rust
let x = 5; // Внешняя x

let y = {
    let x = 3; // Внутренняя x (затенила внешнюю)
    x + 1      // Вернёт 4
};

println!("y = {y}"); // Выведет: y = 4
println!("x = {x}"); // Выведет: x = 5 (внешняя x осталась цела и невредима!)
```

### 💡 Шпаргалка для памяти:

1. Нужно собрать сложный объект/число из кучи мелких расчетов? → **Упакуй в `let x = { ... };`**.
    
2. Хочешь вернуть значение из блока? → **Не ставь `;` на последней строчке!**
    
3. Всё, что было объявлено внутри `{}` - **исчезает навсегда** после закрывающей `}`.
