> **Главная суть:** Срез (**Slice**) - это **ссылка** на последовательный фрагмент коллекции (строки, массива, вектора) **без копирования** самих данных.

### 1. Строковые срезы (`&str`)

Строковый срез указывает на часть строки `String` или на строковый литерал.



```Rust
let s = String::from("hello world");

// Берем фрагменты по индексам [начало..конец] (конец не включается!)
let hello: &str = &s[0..5];  // "hello"
let world: &str = &s[6..11]; // "world"
```

#### Сокращения синтаксиса диапазонов:

- `&s[0..5]` $\rightarrow$ `&s[..5]` _(если с самого начала)_
    
- `&s[6..s.len()]` $\rightarrow$ `&s[6..]` _(если до самого конца)_
    
- `&s[0..s.len()]` $\rightarrow$ `&s[..]` _(весь объект как срез)_
    

> ⚠️ **Важно:** Строковые литералы (`let s = "hello";`) **уже** имеют тип `&str`! Это срез, указывающий на бинарник программы.

### 2. Срезы массивов и векторов (`&[T]`)

Срезы работают не только со строками, но и с любыми коллекциями (массивы, векторы).



```Rust
let a = [1, 2, 3, 4, 5]; // Обычный массив типа [i32; 5]

let slice: &[i32] = &a[1..3]; // Срез содержит [2, 3]
```

- **Тип среза:** `&[i32]` (читается как _«ссылка на срез элементов типа i32»_).
    
- Он хранит указатель на первый элемент среза и его длину.
    

### 3. Срезы как параметры функций (Лучшая практика!)

Если ты пишешь функцию, которая принимает строку, лучше передавать **`&str`**, а не `&String`. Это делает функцию универсальной!



```Rust
fn first_word(s: &String) -> &str {
    let bytes = s.as_bytes(); // Конвертируем строку s в срез байтов

    for (i, &item) in bytes.iter().enumerate() { // i - индекс, item - байт (буква)
        if item == b' ' { // Если наткнулись на пробел
            return &s[0..i]; // Возвращаем срез от начала до пробела
        }
    }

    &s[..] // Если пробела нет, возвращаем всю строку целиком как срез
}

fn main() {
    let s = String::from("hello world"); 

    let my_literal = "hello world";
    let word2 = first_word(my_literal); // Работает напрямую с литералом &str

    let word = first_word(&s); // Передаем ссылку на String
    println!("{}", word); // Выведет "hello"

    // s.clear(); // Если раскомментируешь и переставишь ВЫШЕ println!, Rust не скомпилирует код!
}
```

### 💡 Главные правила срезов для запоминания:

1. **Не владеют данными:** Срез - это всегда ссылка, он не удаляет память при закрытии скобки.
    
2. **Безопасность:** Если у тебя есть неизменяемый срез (`&str`), Rust **запретит менять** исходную коллекцию (`String` / массив), пока этот срез используется. Это защищает от ошибок!
