## 🎲 Крейт `rand`: Колесо Фортуны

В Rust **нет** встроенного генератора случайных чисел, его даже в стандартной библиотеке нет. Поэтому всю случайность берут из крейта (библиотеки) **`rand`**. `rand` это гонец, который бросает кости за тебя.

### 📦 1. Как подключить

Открой терминал в папке проекта и напиши:

```bash
cargo add rand
```

Cargo сам допишет строчку в `Cargo.toml` в раздел `[dependencies]`. Версию можно посмотреть там же. Это важно, потому что в версиях 0.9 и 0.10 переименовали много функций и трейтов, а в старых туториалах ты увидишь старые названия.

> ⚠️ **ЛОВУШКА ВЕРСИЙ:** `rand` часто ломает старый код при обновлении. Если скопировал код из старого видео и компилятор ругается на `gen_range`, `thread_rng` или `Rng`, значит, у тебя новая версия, а код старый.
>    Версия                       Что поменялось
> |0.8 → 0.9|`thread_rng()` → `rng()`, `gen_range()` → `random_range()`, `gen_bool()` → `random_bool()`, `gen()` → `random()`|
> |0.9 → 0.10|Трейт `Rng` → `RngExt` (меняется строка с `use`)|
> В 0.10 имя `Rng` не пропало, а теперь означает **другой** трейт (низкоуровневый, бывший `RngCore`). Поэтому старый `use rand::Rng;` компилируется с предупреждением «unused import», а методы всё равно не находятся.

### 🎰 2. Простейший бросок: `rand::random()`

Хочешь просто случайное число, не заморачиваясь? Вызывай `random()`:

```Rust
fn main() {
    let a: u8 = rand::random();        // случайное число от 0 до 255
    let b: f64 = rand::random();       // случайное дробное от 0.0 до 1.0
    let c: bool = rand::random();      // орёл или решка

    println!("{a} {b} {c}");
}
```

Обрати внимание, что Rust должен **знать тип**, что бы компилятор понимал какого чёрта тебе от него надо. Поэтому пишем `let a: u8`. Если тип не указать, он не поймёт, что от него хотят.

### 🏺 3. Свой Генератор: `rand::rng()`

`random()` удобен для одного броска. Но если тебе нужно **много** бросков и разных, то заводишь **собственного раба** (генератор):

```Rust
use rand::RngExt;
// ^ ВАЖНО! Без этой строки методы ниже не появятся!
// rand 0.10 и новее: RngExt
// rand 0.9 и старше: use rand::Rng;

fn main() {
    let mut rng = rand::rng(); // позвали гонца (mut, потому что он меняется при каждом броске)
    // rand 0.9 и новее: rand::rng()
    // rand 0.8 и старше: rand::thread_rng()

    let rectangle = rng.random_range(1..=6);    // от 1 до 6 ВКЛЮЧАЯ шестёрку
    let percentages = rng.random_range(0..100); // от 0 до 99 (сотня НЕ входит!)
    let chance = rng.random_bool(0.3);          // true с шансом 30%
    // rand 0.9 и новее: random_range() и random_bool()
    // rand 0.8 и старше: gen_range() и gen_bool()

    println!("Кубик: {rectangle}, процент: {percentages}, шанс: {chance}");
}
```

#### 🔍 Разбор по кусочкам

- **`use rand::Rng;`**: это «удостоверение», которое даёт жрецу право бросать кости. `Rng` это трейт (набор умений). Если его не импортировать, Rust скажет, что метода `random_range` не существует. Это самая частая ошибка новичков!
- **`let mut rng`**: `mut` нужен, потому что внутри генератора после каждого броска меняется его состояние.
- **`1..=6`** и **`0..100`**: это диапазоны. Со знаком `=` правая граница **входит**, без него **не входит**.

### 🎴 4. Работа со списками: выбрать и перетасовать

Для векторов нужны ещё два «удостоверения» из модуля `seq`:

```Rust
use rand::seq::{IndexedRandom, SliceRandom};
// IndexedRandom (метод choose) появился в rand 0.9.
// В rand 0.8 и старше choose жил в SliceRandom, а IndexedRandom не было.
use rand::RngExt; // rand 0.10+ (в 0.9 и старше: use rand::Rng;)

fn main() {
    let mut rng = rand::rng();
    let mut rabs = vec!["Спартак", "Гай", "Марк", "Люций"];

    // Выбрать ОДНОГО случайного (вернёт Option, вдруг список пустой!)
    if let Some(lucky) = rabs.choose(&mut rng) {
        println!("Свободу получает: {lucky}");
    }

    // Перемешать весь список (меняет сам вектор, поэтому он mut)
    rabs.shuffle(&mut rng);
    println!("Новый порядок: {rabs:?}");
}
```

#### 🔍 Разбор по кусочкам

- **`choose`** возвращает `Option`, потому что из пустого списка выбирать нечего. Rust заставляет тебя об этом подумать.
- **`&mut rng`**: мы **даём жрецу в аренду** (помнишь заимствование?). Метод берёт у нас изменяемую ссылку на генератор, потому что генератор меняется, когда бросает.
- **`shuffle`** меняет сам список, а не создаёт новый. Поэтому у `рабы` стоит `mut`.

### 🌱 5. Зерно (Seed): одинаковая судьба каждый раз

Обычный генератор каждый раз выдаёт разные числа. Но иногда нужно, чтобы случайность была **повторяемой**: для тестов, для игры, где мир строится по «зерну» (как в Minecraft). Тогда генератору дают **зерно**:

```Rust
use rand::{RngExt, SeedableRng};
// RngExt: rand 0.10+ (в 0.9 и старше: Rng)
use rand::rngs::StdRng;

fn main() {
    let mut rng = StdRng::seed_from_u64(42); // зерно 42

    let x = rng.random_range(1..=100);
    println!("{x}"); // при КАЖДОМ запуске будет одно и то же число!
}
```

Одно и то же зерно даёт одну и ту же последовательность «случайных» чисел. Это называется **псевдослучайность**: числа выглядят случайными, но на самом деле считаются по формуле от зерна.
#### 🩺 6. Как не мучиться с версиями: читай компилятор

Когда код не компилируется из-за версии, **не гугли сразу**. Компилятор Rust обычно сам говорит, что делать. Например, при ошибке с `random_range` он выдал такую подсказку:

``` bash
help: trait `RngExt` which provides `random_range` is implemented but not in scope;
      perhaps you want to import it
  1 + use rand::RngExt;
```

Это значит: «метод существует, но трейт не импортирован, вот строка, которую надо добавить». Ищи в выводе слово **`help:`**. Подсказки компилятора для конкретной версии, которая стоит у тебя, точнее любого туториала

#### 🧠 Короткая шпаргалка

1. `cargo add rand`: подключить крейт.
2. `rand::random::<тип>()`: один быстрый бросок, тип указать обязательно.
3. `let mut rng = rand::rng();` + `use rand::RngExt;`: свой генератор, без `use` методы не найдутся.
4. `rng.random_range(1..=6)`: число в диапазоне (`..=` включает конец, `..` не включает).
5. `rng.random_bool(0.3)`: `true` с заданным шансом.
6. `.choose(&mut rng)` и `.shuffle(&mut rng)`: выбрать из списка и перемешать (нужен `use rand::seq::{IndexedRandom, SliceRandom};`).
7. `StdRng::seed_from_u64(42)`: повторяемая случайность по зерну.
8. **Версия важна!**
    - 0.8 и старше: `thread_rng()`, `gen_range()`, `gen_bool()`, трейт `Rng`
    - 0.9: `rng()`, `random_range()`, `random_bool()`, трейт `Rng`
    - 0.10: `rng()`, `random_range()`, `random_bool()`, трейт **`RngExt`**
9. Что-то не компилируется после обновления? Ищи в ошибке **`help:`**, там обычно готовое решение.
