## **Что такое буфер**

Буфер - это временное хранилище в оперативной памяти (в нашем случае обычная строка `String`), куда ты пошагово складываешь текст перед тем, как выдать его на экран.

Представь, что ты собираешь коробку с вещами: ты не бегаешь на почту с каждой отдельной футболкой (`println!`), а сначала складываешь всё в один ящик (`buf`), заклеиваешь его и относишь целиком за один раз (`print!`).

**Примеры кода**

**1. Простая запись и передача буфера**

```Rust
use std::fmt::Write;

fn main() {
    // 1. Создаем буфер в памяти
    let mut buf = String::with_capacity(512);

    // 2. Наполняем его через функции
    add_user_info(&mut buf, "MBKCHEL");
    add_system_status(&mut buf, true);

    // 3. Выводим всё содержимое один раз
    print!("{}", buf);
}

fn add_user_info(buf: &mut String, username: &str) {
    // Запись напрямую в строку без вывода в консоль
    let _ = writeln!(buf, "Пользователь: {}", username);
}

fn add_system_status(buf: &mut String, is_active: bool) {
    let status = if is_active { "Работает" } else { "Отключен" };
    let _ = writeln!(buf, "Статус системы: {}", status);
}
```

**2. Накопление данных в цикле (например, список процессов)**



```Rust
use std::fmt::Write;

fn append_processes(buf: &mut String) {
    let processes = vec![("sysprint", "12 MB"), ("hyprland", "140 MB"), ("kitty", "45 MB")];

    let _ = writeln!(buf, "--- Список процессов ---");
    for (name, ram) in processes {
        // Каждый круг цикла дописывает новую строчку в буфер
        let _ = writeln!(buf, "ПО: {:<10} | OЗУ: {}", name, ram);
    }
}
```

**Плюсы и минусы использования буферов**

**Плюсы**

- **Огромная скорость:** Вывод текста на экран (I/O) - очень медленная операция. Запись 100 строк в память и один `print!` работает в десятки раз быстрее, чем 100 отдельных `println!`.
    
- **Удобство обработки:** Когда вся информация собрана в одну переменную `String`, её легко разбить на строки (`buf.lines()`), посчитать длину, выровнять или приклеить рядом с ASCII-логотипом.
    
- **Экономия ресурсов CPU:** Процессор не отвлекается на постоянное переключение контекста для работы с терминалом.
    

**Минусы**

- **Расход оперативной памяти:** Текст временно занимает место в RAM, пока не будет выведен и очищен.
    
- **Отсутствие реального времени:** Если программа собирает данные слишком долго, пользователь ничего не увидит в консоли, пока весь буфер полностью не заполнится и не напечатается.
    
- **Дополнительный код:** Приходится протаскивать ссылку `&mut String` через аргументы функций и обрабатывать макросы вроде `writeln!`.
