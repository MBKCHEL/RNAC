`println!` (print line) - это основной инструмент для вывода текста в консоль (терминал) с автоматическим переносом строки в конце.

### ⚠️ Восклицательный знак `!` - это важно!

Символ `!` в конце означает, что это **не обычная функция (метод), а МАКРОС**.

- **Почему макрос?** Обычная функция в Rust требует строго фиксированное количество аргументов одного типа. Макрос `println!` - это мини-генератор кода. Он умеет принимать сколько угодно переменных разных типов и сам «под капотом» собирает их в одну строку.
    
- **Безопасность:** Если ты указал место под переменную, но забыл её передать, компилятор выдаст ошибку еще _до_ запуска программы.
    

### 🚀 Варианты использования (Шпаргалка)

#### 1. Вывод простого текста


```rust
println!("Привет, геймдев!");
```

#### 2. Вывод переменной (использование `{}`)

Фигурные скобки `{}` - это «placeholder» (пустое место), куда компилятор подставит значение переменной, идущей через запятую.


```rust
let player_x = 5;
println!("Координата игрока по X: {}", player_x);
// Выведет: Координата игрока по X: 5
```

#### 3. Вывод нескольких переменных за раз

Переменные подставляются строго по очереди: первая переменная - в первые скобки, вторая - во вторые.


```rust
let x = 5;
let y = 10;
println!("Игрок находится на позиции X: {}, Y: {}", x, y);
// Выведет: Игрок находится на позиции X: 5, Y: 10
```

#### 4. Прямой вывод вычислений

Внутри скобок на месте переменных можно сразу писать математику:


```rust
println!("Результат: {}", 2 + 2); 
// Выведет: Результат: 4
```
