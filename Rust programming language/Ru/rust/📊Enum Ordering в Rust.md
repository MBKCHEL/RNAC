### 1. Что это такое?

`Ordering` (упорядочение) - это **перечисление (enum)** из стандартной библиотеки (`std::cmp::Ordering`). Оно используется для представления **результата сравнения** двух значений.

### 2. Три возможных варианта (`enum variants`)

У `Ordering` есть ровно три состояния:

| **Вариант**             | **Что означает** | **Пример (a относительно b)** |
| ----------------------- | ---------------- | ----------------------------- |
| **`Ordering::Less`**    | Меньше           | `5` меньше `10`               |
| **`Ordering::Greater`** | Больше           | `10` больше `5`               |
| **`Ordering::Equal`**   | Равно            | `5` равно `5`                 |
|                         |                  |                               |

### 3. Как это работает в коде?

Для сравнения используется метод `.cmp()`, который возвращает один из трёх вариантов `Ordering`:



```Rust
use std::cmp::Ordering; // Подключаем enum

let secret_number = 42;
let guess = 10;

// Метод .cmp() сравнивает guess с secret_number
match guess.cmp(&secret_number) {
    Ordering::Less => println!("Слишком мало!"),
    Ordering::Greater => println!("Слишком много!"),
    Ordering::Equal => println!("Вы угадали!"),
}
```

### 💡 Главные фишки для запоминания:

- **Связка с `match`:** `Ordering` идеально работает с конструкцией `match`. Перебираются **все 3 варианта** - если пропустить хоть один, компилятор Rust выдаст ошибку (он следит за полнотой).
    
- **Передача по ссылке:** Метод `.cmp(&secret_number)` принимает **ссылку** (`&`), чтобы не забирать владение переменной.
