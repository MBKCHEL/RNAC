### Что такое кортеж?

Кортеж (tuple) это составной тип данных. Он объединяет несколько значений в одно целое. Его особенности:

- значения могут быть **разных типов**, например `(&str, u8, f64)`;
- размер **фиксирован** и известен при компиляции: после создания добавить или убрать элемент нельзя;
- элементы хранятся **по порядку** и не имеют имён, к ним обращаются по индексу: `.0`, `.1` и так далее;
- записывается в круглых скобках через запятую: `(1, "text", 3.5)`.
### Зачем это?

Кортеж (tuple) нужен, когда нужно сгруппировать несколько значений, причём **разных типов**, и создавать ради этого отдельную структуру (`struct`) нет смысла.

#### Пример 1: Мини-база данных пользователей

```Rust
fn main() {
    let vanya: (&str, u8, f64) = ("Vanya", 20, 1.9); // кортеж 1: имя, возраст, рост
    let danya: (&str, u8, f64) = ("Danya", 45, 2.0); // кортеж 2

    let (name_vanya, age_vanya, height_vanya) = vanya; // распаковка в переменные
    let (name_danya, age_danya, height_danya) = danya; // распаковка в переменные

    println!("Показатели 1 пользователя: Лет: {age_vanya}, Имя: {name_vanya}, рост: {height_vanya} метра");
    println!("Показатели 2 пользователя: Лет: {age_danya}, Имя: {name_danya}, рост: {height_danya} метра");
}
```

Для двух кортежей пришлось придумать разные имена переменных. Если назвать их одинаково, вторая `let` затенит (shadowing) первую, и значения первого кортежа станут недоступны.

#### Пример 2: Возврат нескольких значений из функции

В Rust функция может вернуть несколько значений сразу через кортеж. Не нужны ни отдельная структура, ни `out`-параметры.

```Rust
// Функция возвращает кортеж: (статус-код, текст сообщения)
fn parse_data() -> (u16, &'static str) {
    // ...какая-то логика...
    (200, "Успешно обработано") // возвращаем кортеж
}

fn main() {
    let result = parse_data();

    // Доступ к элементам по индексу через точку
    println!("Код: {}, Ответ: {}", result.0, result.1);
}
```

#### Пример 3: Деструктуризация (распаковка) кортежа

Обращаться к элементам через `.0` и `.1` необязательно. Кортеж можно сразу разложить на отдельные переменные, и обычно это читается удобнее, чем индексы.

```Rust
fn main() {
    // Кортеж с IP-адресом и портом сервера
    let server_address: (&str, u16) = ("127.0.0.1", 8080);

    // Распаковываем в две независимые переменные
    let (ip, port) = server_address;

    println!("Сервер запущен на порту {} по адресу {}", port, ip);
}
```
