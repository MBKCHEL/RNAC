- **`cargo new имя_проекта`** - создаёт новый проект с нуля. Сразу пилит готовую структуру папок, файл `src/main.rs` и, самое главное, `Cargo.toml`, где прописываются все зависимости.
    
- **`cargo build`** - собирает (компилирует) твой проект. В папке `target/debug` появляется готовый `.exe` файл.
    
- **`cargo run`** - компилирует и сразу же запускает код. Самая ходовая команда во время тестов: нажал - проверил.
    
- **`cargo check`** - супер-быстрая проверка кода на ошибки. Она не собирает бинарник, поэтому работает моментально. Удобно запускать, чтобы узнать, ругается компилятор на твой синтаксис или нет, не теряя времени на полную сборку.
- **`cargo buid --release`** - компилирует проект, но для релиза. Компиляция будет дольше, но проект будет максимально оптимизирован. 



- **`rustup update`** - это команда для обновления ЯП компилятора. (Вводить в консоль)

- **`rustup doc`** - это команда открывает локальную документацию в браузере оффлайн. (Вводить в консоль)
