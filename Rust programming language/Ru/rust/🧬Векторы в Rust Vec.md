### 1. Что это такое?

Обычный массив `[i32; 5]` в Rust имеет фиксированный размер в куче/стеке - его нельзя увеличить. **Вектор (`Vec<T>`)** - это динамический массив. Он хранит элементы в куче (Heap), умеет расширяться и сжиматься на лету.

### 2. Способы создания



```Rust
// 1. Пустой вектор через конструктор
let mut v: Vec<i32> = Vec::new();

// 2. Через макрос vec! (сразу с элементами)
let v2 = vec![1, 2, 3];

// 3. С предварительной аллокацией памяти (для оптимизации, если знаешь размер)
let mut v3 = Vec::with_capacity(100);
```

### 3. Добавление и удаление элементов



```Rust
let mut pool: Vec<char> = Vec::new();

// Добавить 1 элемент в конец
pool.push('a');

// Добавить кучу элементов из итератора
pool.extend("bcde".chars());

// Удалить последний элемент (возвращает Option<T>)
let last = pool.pop(); // Some('e')
```

### 4. Доступ к элементам



```Rust
let numbers = vec![10, 20, 30];

// Способ A: Через индексы (ПАСНО! Если индекса нет - программа упадет/panic)
let first = numbers[0]; 

// Способ B: Через .get() (БЕЗОПАСНО! Возвращает Option<&T>)
match numbers.get(0) {
    Some(val) => println!("Число: {}", val),
    None => println!("Элемента нет!"),
}
```

### 5. Обход вектора в цикле (Итерация)



```Rust
let items = vec!["Rust", "C++", "Python"];

// Чтение без изменения элементов
for item in &items {
    println!("{}", item);
}

// Изменение элементов на месте
let mut numbers = vec![1, 2, 3];
for num in &mut numbers {
    *num *= 2; // Умножаем каждое число на 2
}
```

### 6. Чтение элементов вектора
``` Rust
let v = vec![1, 2, 3, 4, 5];

let third: &i32 = &v[2]; // Дали ссылку на 2 элемент вектора v  (0, 1, 2)
println!("Третий эелемент равен: {third}"); // Выводит 3

// Метод .get() безопасно возвращает элемент по индексу в виде перечисления `Option`
match v.get(2){
    Some(third) => println!("Третий элемент равен: {third}"),
    None => println!("Третий элемент отсутствует"),
}
```

### 7. Частые методы, которые спасают жизнь

- `.len()` - текущее количество элементов.

- `.get()` - Метод `.get()` у векторов безопасно возвращает элемент по индексу в виде перечисления `Option`
    
- `.is_empty()` - проверяет, пустой ли вектор (`true`/`false`).
    
- `.contains(&element)` - проверяет, есть ли элемент внутри.
    
- `.clear()` - очищает вектор полностью.
    
- `.choose(&mut rng)` _(из крейта `rand`)_ - дает случайный элемент.
