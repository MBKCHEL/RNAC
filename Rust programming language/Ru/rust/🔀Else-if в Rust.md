В новеллах нам постоянно нужно проверять, какие предметы есть у игрока и какое у него состояние.

### Логические операторы:

- `&&` - **И** (нужно, чтобы совпали оба фактора).
    
- `||` - **ИЛИ** (достаточно, чтобы совпал хотя бы один фактор).
    

## 1. Обычный `if / else if / else`

Используется, когда нужно проверить конкретные условия по очереди. Круглые скобки вокруг условия не нужны, фигурные - обязательны.

### Пример для новеллы:



```Rust
let choice = 2; // Выбор игрока в консоли

if choice == 1 {
    println!("Вы открыли левую дверь.");
} else if choice == 2 {
    println!("Вы открыли правую дверь.");
} else {
    println!("Вы стоите на месте.");
}
```

### Пример: Выбор ответа в диалоге с проверкой двух условий

Представь ситуацию: игрок стоит перед запертой дверью в библиотеке, и с ним говорит напарник.



```Rust
let choice = 2;              // Номер ответа, который ввёл игрок в консоль
let has_key = false;         // Нашёл ли игрок ключ раньше по сюжету
let charisma = 7;            // Уровень прокачки красноречия

if choice == 1 && has_key == true {
    // Условие 1: Игрок выбрал вариант 1 И у него реально есть ключ
    println!("Вы вставляете ржавый ключ в замочную скважину. Дверь со скрипом открывается.");
} else if choice == 2 || charisma >= 5 {
    // Условие 2: Игрок выбрал вариант 2 ИЛИ у него просто высокая харизма
    println!("Вы заговариваете зубы напарнику, и он помогает вам выбить дверь плечом.");
} else {
    // Все остальные случаи (неверный выбор или не хватило статов)
    println!("Напарник смотрит на вас как на дурака. Ничего не происходит.");
}
```
